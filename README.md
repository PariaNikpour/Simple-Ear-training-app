# ear training game
An ear-training game created by python and pygame.
the game plays a random musical note and asks the user to identify it. it includes multiple difficulty levels, notes from different octaves, support for sharp and flat not names, a replay option, scoring and a quit option.


## audio samples
original audio samples used in this project are recorded by the developer using a keyboard.



## features
- choose number of rounds
- five difficulty levels
- play random musical notes from octaves 3, 4 and 5
- sharp and flat note recognition
- replay option
- quit option
- score and percentage calculation



## difficulty levels
### easy
 natural notes in octave 4.  
 the player only has to identify the note name without the octave number  
 for example: A or d.

### medium
natural notes in octaves 3, 4 and 5  
the player only has to identify the note name without the octave number

### hard
natural and sharp notes in octave 4  
the player only has to identify the note name without the octave number  
flat equivalents are also accepted for entrance. for example:  
c# = Db

### expert
natural and sharp notes in octaves 3, 4 and 5  
the player only has to identify the note name without the octave number  
flat equivalents are also accepted for entrance. for example:  
c# = Db

### extreme
natural and sharp notes in octaves 3, 4 and 5  
the player must identify both the note and its octave  
for example: A#3 or db4.
flat equivalents are also accepted for entrance. for example:  
c# = Db


## controls
- enter the note name to submit an answer
- press r to replay the note
- press q to quit the game



## installation
make sure python 3 is installed;then install pygame: 

pip install pygame




## running the game
run the following command inside the project folder:

python EarTrainigApp.py
